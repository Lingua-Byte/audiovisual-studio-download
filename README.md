# Audiovisual Studio: site

Site oficial do Audiovisual Studio: edição de vídeo, design gráfico e produção de áudio em um só programa.

- `index.html`: a página completa
- `media/`: vídeos e imagens usados no site

## Publicar com GitHub Pages

1. No repositório, abra **Settings → Pages**.
2. Em **Source**, escolha **Deploy from a branch**.
3. Escolha a branch `main` e a pasta `/ (root)`, e clique em **Save**.
4. Em um ou dois minutos o site fica no ar em `https://<usuario>.github.io/<repositorio>/`.

O botão de download aponta para o instalador publicado em Releases.
